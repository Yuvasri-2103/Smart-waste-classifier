  # Smart Waste Classifier

  MobileNetV2 CNN that classifies waste into 6 categories, with a Streamlit web app.

  ## Live Demo
  https://smart-waste-classifier-rcmjvmlttyhylzsckvibvd.streamlit.app

  ## Classes
  cardboard, glass, metal, paper, plastic, trash

  ## Run locally
  pip install -r requirements.txt
  streamlit run app.py
